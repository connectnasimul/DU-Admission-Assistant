## ফাইল

```
du-admission-chatbot/
├── index.html    # চ্যাটবটের UI — ফুল-স্ক্রিন, মোবাইল ফ্রেন্ডলি, SVG আইকন
├── api/
│   └── chat.js   # Vercel Serverless Function — Gemini proxy (Key সার্ভার-সাইডে পড়ে)

└── README.md     # এই ফাইল
```

## GitHub-এ আপলোড (ম্যানুয়াল)

1. GitHub-এ নতুন repository বানান, যেমন `du-admission-chatbot` (Public)।
2. **Add file → Upload files** থেকে `index.html`, `api/chat.js` ও `vercel.json` আপলোড করুন (ফোল্ডার কাঠামোসহ — `api` ফোল্ডারটা অবশ্যই রাখবেন, এটা ছাড়া লাইভ AI চলবে না)।
   অথবা কমান্ড লাইনে:
   ```bash
   git init
   git add index.html api/chat.js vercel.json README.md
   git commit -m "DU Admission Assistant Chatbot"
   git branch -M main
   git remote add origin https://github.com/<আপনার-username>/du-admission-chatbot.git
   git push -u origin main
   ```
3. Repository-র **Settings → Pages** থেকে GitHub Pages-এও সাইটটি দেখা যাবে
   (Branch: `main`, Folder: `/ (root)`) — তবে সেখানে লাইভ AI চলবে না, কারণ
   GitHub Pages স্ট্যাটিক হোস্টিং; `/api/chat` শুধু Vercel-এই চলে। জমা দেওয়ার
   লাইভ লিঙ্ক হিসেবে Vercel লিঙ্কটাই ব্যবহার করবেন।

## ▲ Vercel-এ লাইভ লিঙ্ক

1. [vercel.com](https://vercel.com) → **Add New → Project** → GitHub repository
   `du-admission-chatbot` Import করুন।
2. Framework Preset: **Other** (কিছু বদলাতে হবে না — এটা পিওর স্ট্যাটিক সাইট)।
3. **Deploy** চাপুন। লাইভ লিঙ্ক পাবেন, যেমন:
   `https://du-admission-chatbot.vercel.app`
4. সেই লিঙ্কটাই জমা দিন।

> লাইভ AI-এর জন্য একটাই environment variable লাগে: `GEMINI_API_KEY`
> (নিচের Gemini API অংশ দেখুন)। Key কখনো ব্রাউজারে বা কোডে থাকে না — শুধু
> Vercel-এর সার্ভারে, `api/chat.js` সেটা পড়ে।

## Gemini API লাইভ করা (ফ্রি) — Vercel Environment Variable দিয়ে

UI-তে API Key বসানোর কোনো অপশন নেই — Key থাকে শুধু Vercel-এ, সার্ভার-সাইডে।

1. [aistudio.google.com](https://aistudio.google.com) → **Get API Key** →
   **Create API key** (ফ্রি tier-এই চলে)।
2. Vercel Dashboard → আপনার প্রজেক্ট → **Settings → Environment Variables**।
3. **Add New**: Name `GEMINI_API_KEY`, Value আপনার Key → Environment **Production** (চাইলে Preview-ও) → **Save**।
4. **Deployments → ⋯ → Redeploy** করুন (env var যোগ/বদল করলে redeploy লাগে)।
5. এরপর চ্যাটবট Gemini দিয়ে লাইভ উত্তর দেবে।

Key না থাকলে, ভুল হলে, বা API ব্যর্থ হলে বট স্বয়ংক্রিয়ভাবে অফলাইন
জ্ঞানভাণ্ডার থেকে উত্তর দেবে — চ্যাট কখনো থামবে না। লোকালভাবে
(`index.html` সরাসরি খুললে) `/api/chat` থাকে না, তাই সেখানে সবসময়
অফলাইন মোড চলবে — এটাই স্বাভাবিক।

## বটে থাকা যাচাইকৃত তথ্য (২০২৬–২৭ সেশন)

সূত্র: অফিসিয়াল ভর্তি পোর্টাল `admission.eis.du.ac.bd` ও প্রকাশিত নির্দেশনা
(নভেম্বর ২০২৬ অনুযায়ী)। আবেদন বা ফি জমা দেওয়ার আগে অফিসিয়াল সার্কুলার
অবশ্যই যাচাই করুন — তারিখ ও ফি সার্কুলার অনুযায়ী বদলাতে পারে।

- **আবেদন:** ১১ – ২৫ নভেম্বর ২০২৬
- **পরীক্ষা:** IBA ৫ ডিসেম্বর ২০২৬ · বিজ্ঞান ইউনিট ১২ ডিসেম্বর ২০২৬ · চারুকলা ২২ ডিসেম্বর ২০২৬
- **আবেদন ফি (প্রতি ইউনিট):** বিজ্ঞান / কলা, আইন ও সমাজবিজ্ঞান / ব্যবসায় শিক্ষা ৳১,২০০ · চারুকলা ৳১,৪০০ · IBA ৳১,৫০০
- **যোগ্যতা (মোট GPA, SSC+HSC):** বিজ্ঞান ৮.০০ (প্রতিটিতে কমপক্ষে ৩.৫০) · কলা, আইন ও সমাজবিজ্ঞান ৭.৫০ (৩.০০) · ব্যবসায় শিক্ষা ৭.৫০ (৩.০০) · চারুকলা ৬.৫০ (৩.০০)
- **ডকুমেন্টস:** SSC ও HSC-র রোল/বোর্ড/পাসের বছর, নিজের মোবাইল নম্বর ও ইমেইল, বর্তমান ঠিকানা, সাদা ব্যাকগ্রাউন্ডের রঙিন ছবি (কমপক্ষে ৪৫০×৫৫০ px, JPG), অভিভাবকের NID (ঐচ্ছিক), কোটার প্রমাণপত্র (প্রযোজ্য হলে)
- **টিউশন ফি:** ঢাবি পাবলিক বিশ্ববিদ্যালয় — টিউশন ফি বিভাগ ও সেমিস্টার অনুযায়ী আলাদা হয়; সঠিক অঙ্ক অ্যাডমিশন অফিস থেকে নিশ্চিত করতে হয়।
